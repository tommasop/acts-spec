Start a new ACTS v2 stack (feature) — creates the base branch and `.acts/stack.json` manifest.

Usage: `/acts-stack <id> <title>`

Run `acts stack create $ARGUMENTS`.

Then add the first change: `acts change add c1 -t "<first change title>" --accept "<acceptance criteria>"`
